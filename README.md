# Tutorly

Tutorly is an Android app that connects university students who need academic help with peers willing to tutor. Users create forum posts by course, find matches, coordinate session times, and manage their tutoring profile.

## Features

- **Authentication** — Register and log in with Firebase Auth; password validation on sign-up.
- **Profiles** — Customizable user profiles with tutored courses, availability, bio, and profile color; like other tutors to show appreciation.
- **Forum** — Create and browse posts by course code and subject; filter by course, help type, or your own posts; comment on post threads.
- **Matching & scheduling** — Match with tutoring posts, propose and confirm session times, and track match status (active, matched, closed).
- **Notifications** — View match activity, schedule updates, and reports in one place.
- **Admin tools** — Admins can review users and posts, ban accounts, and delete inappropriate content.
